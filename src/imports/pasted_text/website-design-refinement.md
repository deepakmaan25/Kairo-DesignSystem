Refine the current website design without changing its core structure, content flow, navigation model, or overall product concept.

This is NOT a full redesign from scratch.
Do NOT replace the existing layout system with a completely different concept.
Do NOT turn it into a new style direction.
Do NOT make it feel like a different website.
Do NOT remove the work that is already implemented.

Instead, keep the current foundation and improve it on the design level where it currently feels basic, flat, generic, or underdeveloped.

PRIMARY GOAL
Preserve the existing website’s architecture and interaction model, but elevate the visual design so it feels:
- more premium
- more intentional
- more polished
- more modern
- more memorable
- more professionally art-directed

Think of this as a visual refinement pass, not a reinvention.

WHAT MUST STAY THE SAME
Keep these intact unless there is a very minor polish reason to adjust them:
- overall information architecture
- section order and flow
- navigation logic
- command palette concept
- component lab concept
- content purpose of each section
- current design-system-driven foundation
- accessibility improvements already implemented
- existing interactions that are already working well

Do not introduce a radically different layout, page structure, or storytelling concept.

WHAT TO IMPROVE
Focus only on elevating areas that currently feel too basic or default:
- typography hierarchy and rhythm
- spacing consistency and breathing room
- section composition and alignment
- surface treatment and material quality
- depth, layering, and elevation
- polish of cards, panels, and containers
- hover, focus, pressed, and transition states
- hero art direction
- visual cohesion across all sections
- overall emotional impact and memorability

DESIGN DIRECTION
Aim for an Apple-like level of polish and restraint:
- minimal but not empty
- elegant and precise
- premium materials and depth
- calm, high-end surfaces
- subtle translucency where appropriate
- refined shadows and borders
- strong hierarchy
- crisp typography
- smooth and natural motion
- modern and professional

Do not literally copy Apple.
Instead, capture the same qualities:
- clarity
- hierarchy
- harmony
- consistency
- depth
- deference to content

PRESERVATION RULE
Before changing anything, ask:
“Can this be improved without changing its identity?”
If yes, refine it.
If no, leave it.

Only make changes that feel like:
- better styling
- better spacing
- better proportions
- better motion
- better materials
- better hierarchy
- better polish

Do not make changes that feel like:
- new concept
- new product
- new layout system
- new content strategy
- new navigation paradigm

SPECIFIC VISUAL IMPROVEMENTS
Apply refinement in these ways:
- make sections feel more intentionally composed
- improve whitespace and visual rhythm
- upgrade containers with more refined radius, borders, shadows, and surface contrast
- make hero visuals more striking while keeping the same role and purpose
- make typography feel more premium and confident
- improve card layouts so they feel designed, not just stacked
- enhance color restraint and material balance
- add subtle depth and layering
- improve the finish of interactive controls
- unify the feel of all components and panels

MOTION DIRECTION
Keep motion subtle and premium.
Do not add excessive animation.
Use motion only to improve elegance and quality:
- smoother entrances
- better hover transitions
- refined state changes
- subtle layered movement
- premium easing
- polished theme switching
- graceful section reveals

If an animation feels flashy, remove it.
If an animation makes the site feel more expensive and considered, keep it.

INTERACTION RULE
Do not change how the site basically works.
Only improve how it feels.

Examples:
- keep the command palette, but style and transition it more beautifully
- keep the component exploration, but improve the visual presentation
- keep the footer structure, but refine spacing, hierarchy, and material treatment
- keep the hero concept, but make it more art-directed and polished

COMPONENT + SECTION TREATMENT
Every existing section should remain recognizable, but visually elevated.
Make the site feel like the same product after a top-tier design pass.

Do not rebuild sections into completely different patterns unless absolutely necessary.
Prefer:
- refinement over replacement
- polish over novelty
- consistency over experimentation
- elegance over quantity

DESIGN SYSTEM FIDELITY
Use the current design system as the base.
Do not abandon it for a new visual language.
Refine within the system first.
If a new treatment is introduced, it should feel like a natural extension of the current design system, not a contradiction.

FINAL TEST
The final result should make someone say:
“This is clearly the same website — just far more refined, premium, and memorable.”

It should NOT make someone say:
“This is a totally different site.”

SUCCESS CRITERIA
- same structure
- same core experience
- same recognizability
- stronger hierarchy
- better materials
- more elegant motion
- more premium finish
- more memorable design language
